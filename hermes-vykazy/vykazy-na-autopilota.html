Výkazy na autopilota

Jak z nahrávek schůzek, hlasových poznámek a vybraných podkladů nechat AI agenta skládat denní záznam práce a týdenní výkaz. Ty jen zkontroluješ a odešleš. Než začneš

2.1Kontrolní seznam: ověř dřív, než něco koupíš nebo zapneš

  • Pravidla zaměstnavatele. Smíš v práci používat AI nástroje, a které? Platí to i pro model u čínského poskytovatele? Bez souhlasu nenapojuj pracovní e-mail ani Teams. Viz 2.2 a 6.3.
  • Účet Plaud z Hongkongu. Než koupíš zařízení, nainstaluj aplikaci Plaud a zaregistruj účet. Podmínky Plaud Hongkong z omezení výslovně vyjímají (viz 5.1); registrace je praktická zkouška zdarma.
  • Registrace u modelu z Hongkongu. Hongkong jsem v oficiálních seznamech regionů Kimi ani Z.ai výslovně nenašel. Zaregistruj se, nabij minimum ($1 u Kimi) a vytvoř API klíč. Když to projde, jsi v pořádku. Viz 3.3.
  • Žádný GLM Coding Plan. Pro Hermes jen běžný API klíč s placením podle spotřeby. Viz 3.3.
  • WhatsApp: druhé číslo? Pokud chceš agenta ve WhatsAppu, rozhodni předem, jestli mu dáš samostatné číslo (doporučené) nebo budeš psát sám sobě. Viz 3.4.
  • Cena modelu. Odhad $5,5 až $13,5 měsíčně je výpočet z předpokladu. Po prvním týdnu zkontroluj skutečnou spotřebu příkazem /usage. Viz 3.3.
  • Automatické stahování z Plaud. Napojení Plaud MCP na Hermes nebylo vyzkoušené. Začni sdílením shrnutí do chatu; automatiku zkus až po prvním týdnu. Viz 5.4.

2.2Čtyři pravidla

  1. Zeptej se zaměstnavatele, jestli smíš používat AI nástroje a které. Hongkongský úřad pro ochranu osobních údajů (PCPD) vydal 31. 3. 2025 checklist pro firemní pravidla používání generativní AI. Doporučuje firmám určit, které platformy smí zaměstnanci používat, k jakým účelům a jaké informace do nich smí vkládat. Pokud firma taková pravidla má, mají přednost před tímto návodem. U klientů z veřejného sektoru nebo s citlivými projekty může vadit i to, že model běží u čínského poskytovatele.
  2. Na začátku schůzky řekni, že nahráváš a proč. Případová poznámka PCPD 2020E02 uvádí, že zákon o ochraně osobních údajů (PDPO) nahrávání nezakazuje. Když ale nahrávka zachycuje osobní údaje, platí pro ni zásady zákona. Úřad doporučuje lidi předem informovat, že se nahrává a k čemu. Plaud sám uvádí, že souhlas účastníků je odpovědností uživatele.
  3. Dávej agentovi co nejméně dat. Posílej shrnutí, ne celé přepisy, a nenapojuj pracovní e-mail. PCPD 25. 8. 2026 vydal pokyny k agentní AI. Doporučuje dávat agentům jen nezbytně nutný přístup, omezovat doplňky a používat aktuální oficiální verze. Už v březnu 2026 úřad varoval, že agent může omylem smazat data a že neprověřené skilly a pluginy mohou obsahovat škodlivý kód. Proto instaluj jen skilly, které znáš, například ten z tohoto návodu.
  4. Vědět, kudy data tečou. Hermes běží u tebe a podle dokumentace neodesílá žádnou telemetrii; data jdou jen k poskytovateli modelu. Kimi i Z.ai (GLM) ve svých podmínkách pro API uvádějí, že vstupy z API nepoužívají k trénování modelů (u Z.ai pokud s tím výslovně nesouhlasíš). Obě firmy uvádějí zpracování v Singapuru. Plaud ukládá data asijských účtů v AWS Singapur a podle svého Trust Center na nich bez souhlasu netrénuje.

Tohle není právní poradenství. Vládní odpověď Legislativní radě z 14. 6. 2017 (LCQ17) k nahrávání rozhovoru jeho účastníkem jsem v plném znění neověřil. Sekundární zdroje ji citují tak, že zákon účastníkovi rozhovoru nahrávání nezakazuje.

# Worklog

Turns voice notes, Plaud meeting summaries, forwarded documents and short text
notes into an evidence-based daily work log and a weekly report / timesheet.
All files live in the WorkLog folder (see AGENTS.md in that folder for the
owner's role, project list, project codes and report format).

## When to Use

- The user sends a message, voice note or file that starts with "log", "worklog",
  "note" or is a shared Plaud summary / transcript.
- The user types `/worklog` with or without text.
- A scheduled job asks for "DAILY CLOSE", "WEEKLY REPORT" or "IMPACT DIGEST".

## Folder layout (inside the WorkLog folder)

- `inbox/` raw inputs, one file per item: `YYYY-MM-DD_HHMM_<source>_<short-title>.md`
- `daily/YYYY-MM-DD.md` daily log
- `weekly/YYYY-Www.md` weekly report (ISO week), optional `.docx` copy
- `impact-log.md` running list of notable contributions
- `templates/weekly-template.md` the employer's report format (if present, follow it exactly)

## Procedure

### A. CAPTURE (any incoming note, voice note or file)

1. Save the raw input to `inbox/` using the naming pattern above. For files, store
   the extracted text, not the original binary. Keep the original wording.
2. Extract work entries. One entry = one activity:
   `start time | duration (h) | project code | category | what was done | with whom | source`
   Categories: Design, Coordination & meetings, Review & QA, Support for others,
   Site, Documentation, Admin, Other.
3. Append the entries to `daily/<today>.md` (create it if missing).
4. Reply in ONE short line: what was logged and anything missing
   (e.g. "Logged 1.5 h P-2301 Review & QA. Missing: who requested it?").

### B. DAILY CLOSE (scheduled, weekdays)

1. Read today's `inbox/` files and `daily/<today>.md`.
2. Merge duplicates (a Plaud meeting and a voice note about the same meeting are
   one entry). Sort by start time.
3. Write the final table to `daily/<today>.md` with a total of hours and a
   "Gaps" list (missing durations, unknown project codes, unexplained time).
4. Add any notable contribution (problem solved, risk caught, rework of someone
   else's output, decision unblocked) to `impact-log.md` with date and source.
5. Reply with: total hours, 3-6 bullet summary, the Gaps list as questions.
   Keep it under 120 words.

### C. WEEKLY REPORT (scheduled, Friday)

1. Read `daily/` files for Monday to today of the current ISO week and the
   week's entries in `impact-log.md`.
2. If `templates/weekly-template.md` exists, follow its structure exactly.
   Otherwise produce:
   - Timesheet table: project code, project name, hours per day, total.
   - Key outcomes (5-8 bullets, outcome first, then evidence).
   - Coordination and meetings (count and total hours).
   - Support and quality assurance for others (see Pitfalls for wording).
   - Next week: open items and risks.
3. Save to `weekly/YYYY-Www.md`. If asked for Word, also create the `.docx`.
4. Reply with a 5-line summary and attach the file using `MEDIA:<absolute path>`.
   This is a DRAFT for the user to review. Never send it to anyone else.

### D. IMPACT DIGEST (scheduled, monthly)

Summarise the last month of `impact-log.md` into 5-10 achievement statements
suitable for a performance review: situation, action, result, evidence.

## Pitfalls

- Never invent hours, people, decisions or project codes. Durations come only
  from recording length, an explicit statement by the user, or a calendar entry.
  If unknown, write `?` and list it under Gaps.
- Every entry must name its source (Plaud recording title and time, voice note
  time, email subject, file name).
- Rework or fixes of other people's work: describe the issue and the fix in
  neutral, factual language. No blame, no adjectives about colleagues, no names
  unless the user explicitly asks. Example: "Corrected grid references in the
  tender drawing set (24 sheets) before issue; prevented a re-issue." NOT
  "Fixed X's careless mistakes again."
- Do not copy full meeting transcripts into reports. Summarise outcomes only.
- Do not include client-confidential details (fees, disputes, personal data)
  in the weekly report unless the user explicitly asks.
- Use the language and spelling set in AGENTS.md (default: British English).

## Verification

- Daily file total equals the sum of the table rows.
- Every row has a source.
- Weekly totals per project equal the sum of the daily files.
    hermes skills list | grep worklog

    Každý skill je zároveň příkaz: v chatu funguje /worklog Spent 2 h correcting the door schedule before tender issue.

  6. Propoj WhatsApp nebo Telegram

    A) WhatsApp

    1. Rozhodni režim (viz 3.4): bot = samostatné číslo pro agenta, self-chat = píšeš sám sobě na svém čísle.
    2. Spusť průvodce a v telefonu (u čísla, které bude agent používat) otevři WhatsApp → Nastavení → Propojená zařízení → Propojit zařízení a naskenuj QR kód. Kód se obnovuje asi po 20 sekundách.
    3. Povol jen své číslo: předvolba bez „+“, pro Hongkong 852.
    4. Spusť gateway jako službu a v chatu s agentem pošli /sethome.
    hermes whatsapp          # průvodce: režim bot / self-chat, pak QR kód
hermes config set WHATSAPP_ALLOWED_USERS 852XXXXXXXX
hermes gateway install   # gateway poběží na pozadí
hermes gateway status

    Telefon s číslem agenta musí být občas online; po delší nečinnosti WhatsApp propojené zařízení odpojí a stačí znovu spustit hermes whatsapp. Když napojení po aktualizaci WhatsAppu přestane fungovat, pomůže hermes update a nové spárování.

    B) Telegram

    V Hermes Desktop: Messaging → Telegram → Create with QR. Naskenuješ kód v Telegramu, Hermes vytvoří bota a zapíše tvoje ID jako jediného povoleného uživatele. Ručně: hermes gateway setup, vyber Telegram a token získej u @BotFather. Pak hermes gateway install a v chatu s botem /sethome.

    Nikdy nepovoluj všechny uživatele (GATEWAY_ALLOW_ALL_USERS=true ani WHATSAPP_ALLOWED_USERS=*).

  7. Hlasové poznámky

    Hlasové zprávy poslané agentovi do WhatsAppu i Telegramu se automaticky přepíšou na text. Výchozí přepis běží lokálně (faster-whisper, bez API klíče; nefunguje na Intel Macu a Windows ARM64). Nastav angličtinu a slovník jmen a projektů:

    hermes config set stt.language en
hermes config set stt.prompt "Revit, BIM, Buildings Department, [jména projektů], [jména kolegů]"

    Návyk: začínej poznámku slovem „Log“. Například: „Log. About an hour and a half on the Kai Tak façade set, correcting grid references before issue.“

  8. Naplánuj denní uzávěrku, týdenní výkaz a měsíční přehled

    Spusť v terminálu (nahraď cestu). Úlohy běží v hongkongském čase díky kroku 3. Pro Telegram změň --deliver whatsapp na --deliver telegram. Úlohy pak vidíš a spravuješ i v Hermes Desktop.

    hermes cron create "30 18 * * 1-5" "DAILY CLOSE: Use the worklog skill, procedure B, for today's date. Work only inside the WorkLog folder. Reply in English, under 120 words, and end with the Gaps questions." --skill worklog --workdir /Users/TVOJE_JMENO/WorkLog --name "Daily close" --deliver whatsapp

hermes cron create "0 16 * * 5" "WEEKLY REPORT: Use the worklog skill, procedure C, for the current ISO week. Follow templates/weekly-template.md. Save the Markdown file and a .docx copy in weekly/, then attach the .docx. This is a draft for my review only." --skill worklog --workdir /Users/TVOJE_JMENO/WorkLog --name "Weekly report" --deliver whatsapp

hermes cron create "0 10 1 * *" "IMPACT DIGEST: Use the worklog skill, procedure D, for the previous calendar month. Save it as weekly/impact-YYYY-MM.md and attach it." --skill worklog --workdir /Users/TVOJE_JMENO/WorkLog --name "Monthly impact" --deliver whatsapp

    Otestuj hned, nečekej na večer:

    hermes cron list
hermes cron run "Daily close"

    Volitelně, aby šlo na denní souhrn odpovědět opravou a agent věděl, o čem je řeč: hermes config set cron.mirror_delivery true

  9. Zabezpeč

    Výchozí nastavení už blokuje nebezpečné příkazy a neznámé uživatele. Na počítači s pracovními daty dokumentace doporučuje ruční schvalování:

    hermes config set approvals.mode manual

    Session WhatsAppu (složka ~/.hermes/platforms/whatsapp/session) a token Telegram bota chraň jako heslo. Při podezření na únik: WhatsApp → Nastavení → Propojená zařízení → odhlásit; u Telegramu /revoke u @BotFather.

5

Plaud a přepis

5.1Plaud v Hongkongu

  • Smluvní podmínky: oddíl 15.2 obchodních podmínek Plaud vyjmenovává, kde služby nejsou dostupné (Rusko, Bělorusko, Kuba, Írán, Severní Korea, Sýrie, ČLR) a u Číny výslovně uvádí „excluding Hong Kong and Macau“. Spotřebitelská smlouva uvádí jen pevninskou Čínu, pro kterou má Plaud samostatnou aplikaci.
  • Oficiální obchod: hk.plaud.ai prodává zařízení i předplatné AI v HKD.
  • Modely v pozadí: přepis a shrnutí počítá Plaud na svých serverech s modely OpenAI, Anthropic a Google. Omezení těchto firem pro Hongkong se týká přímých zákazníků; Plaud je volá jako svůj dodavatel a hongkongský web Plaud je uvádí jako součást služby. Aktuální seznam modelů ukáže aplikace (Generate → Custom generation → AI model).

5.2Nastavení přepisu

  • Jazyk: Plaud přepisuje vždy v jednom jazyce na nahrávku. U smíšených schůzek vyber převažující jazyk. Podle nápovědy podporuje přes 112 jazyků včetně kantonštiny.
  • Mluvčí: Plaud automaticky pozná jen tvůj hlas (po nastavení hlasového profilu). Ostatní označí jako Speaker 1, 2 a jména jim doplníš ručně. Shrnutí vytvořené před přejmenováním je potřeba vygenerovat znovu.
  • Online schůzky: Plaud Desktop (Mac a Windows) nahraje Teams, Zoom nebo Meet ze zvuku počítače, bez bota ve schůzce. Vyžaduje spárované zařízení Plaud.

5.3Pokyn pro shrnutí, které se hodí do výkazu

V nahrávce zvol Generate → Custom generation a vlož tento pokyn.

Summarise this meeting as a work-log entry in British English.
Output exactly these fields:
Date and start time:
Duration (from the recording length):
Project (name or code if mentioned):
Participants (roles/companies, names only if stated):
Purpose:
Decisions made:
Actions for me (owner = me):
Actions for others:
Issues I raised, caught or resolved (risks, errors, clashes):
Notes for my timesheet (category: Design / Coordination / Review & QA / Support for others / Site / Admin):
Do not invent anything that was not said. Mark uncertain items with "?".

5.4Jak se shrnutí dostane k agentovi

A · StartSdílení do chatu

V aplikaci Plaud exportuj shrnutí (TXT, Markdown, DOCX nebo PDF) a sdílej ho do chatu s agentem ve WhatsAppu nebo Telegramu.

B · AutomatickyPlaud MCP

Agent si dnešní shrnutí stáhne sám při denní uzávěrce.

C · ArchivAutoFlow e-mail

Plaud po přepisu sám pošle přepis nebo shrnutí na zvolenou adresu. Záloha do tvé schránky.

Varianta B: napojení Plaud MCP (po prvním týdnu)

Plaud provozuje oficiální MCP server https://mcp.plaud.ai/mcp. Je jen pro čtení, vyžaduje zapnutý Plaud Cloud Sync a podle nápovědy Plaud je zdarma pro aktivní účty. Data jdou podle dokumentace Plaud přes server v USA a po vyřízení požadavku se tam neukládají. Do ~/.hermes/config.yaml přidej:

mcp_servers:
  plaud:
    url: "https://mcp.plaud.ai/mcp"
    auth: oauth
hermes mcp login plaud     # otevře prohlížeč, přihlásíš se do Plaud

Pak u denní uzávěrky (krok 8) uprav zadání:

hermes cron edit "Daily close" --prompt "DAILY CLOSE: First use the plaud MCP tools to list today's recordings and save each available summary to inbox/ (skip files already saved). Then use the worklog skill, procedure B, for today's date. Work only inside the WorkLog folder. Reply in English, under 120 words, and end with the Gaps questions."

Tuhle kombinaci jsem nemohl vyzkoušet. Dokumentace Hermes upozorňuje, že někteří poskytovatelé MCP vyžadují vlastní OAuth aplikaci. Když přihlášení selže, zůstaň u varianty A.

AutoFlow (varianta C) se nastavuje jen v mobilní aplikaci Plaud: u „Send email“ zvolíš adresu a co posílat. Spouští se jen u nahrávek nad 200 slov (asi 5 minut řeči) a minuty se odečítají z tarifu.

6.2Neviditelná práce a opravy za ostatní

Výkaz má ukázat, co se díky tobě nestalo: chyby zachycené před vydáním, nekoordinované podklady, které jsi srovnal. Formuluj věcně, s rozsahem a důsledkem, bez obviňování. Skill to má v pravidlech.

Takhle neFixed the junior team's careless mistakes on the tender set again.
Takhle anoReviewed and corrected grid references on 24 tender drawings before issue; avoided a re-issue to the contractor.
Takhle neHad to redo structural coordination because nobody checked it.
Takhle anoRe-coordinated slab openings with the structural consultant (3 clashes resolved), unblocking the MEP submission.

Soubor impact-log.md se plní sám při denní uzávěrce. Jednou měsíčně z něj agent udělá 5 až 10 vět ve tvaru situace, akce, výsledek, doklad. Podklad k hodnocení, kde se jinak vzpomíná po paměti.

6.3Firemní systémy (jen se souhlasem IT)

  • Pracovní e-mail. Hermes má vestavěný skill Himalaya pro práci se schránkou přes IMAP/SMTP. Firemní Microsoft 365 často IMAP nebo hesla aplikací vypíná; rozhoduje IT.
  • Přepisy z Microsoft Teams. Hermes má pipeline pro přepisy schůzek z Teams přes Microsoft Graph. Podle dokumentace jsou potřeba práva správce tenantu.
  • Bez napojení: přepis schůzky z Teams si můžeš stáhnout ručně a poslat agentovi jako soubor. Agent čte .docx, .pdf, .txt i .md.

Přeposílání firemní pošty do soukromé schránky nebo k externímu AI poskytovateli bývá v rozporu s interními pravidly. Nedělej to bez písemného souhlasu.
